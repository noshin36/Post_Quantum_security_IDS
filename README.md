This IDS successfully distinguishes ML-DSA signatures from classical ECC with 99% accuracy, identifying the increased packet size and fragmentation typical of post-quantum handshakes
This implements an intelligent Network Intrusion Detection System (NIDS) tailored for the post-quantum era. By analyzing the unique transport-layer fingerprints (packet size, length, and timing anomalies) of NIST-standardized **ML-KEM** and **ML-DSA** protocols, a trained Random Forest model successfully identifies cryptographic downgrade attacks without looking at encrypted payload content.
